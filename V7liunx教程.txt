# Fisher V6 - Ubuntu 24.04 LTS + 宝塔面板 完整搭建教程

> 适用系统：Ubuntu 22.04 LTS / 24.04 LTS (amd64 / arm64) ✅（推荐 24.04 LTS，长期支持稳定版）
> 面板版本：宝塔面板 Linux 正式版 (aapanel 国际版也可参考)
> 最后更新：2026-09

### 需要开放的端口

| 端口 | 协议 | 用途 | 是否必须对外开放 |
|------|------|------|------------------|
| 22   | TCP  | SSH 远程登录 | 建议（可改端口提高安全） |
| 80   | TCP  | HTTP 网站访问 | ✅ 是 |
| 443  | TCP  | HTTPS 网站访问 | ✅ 是（配置了证书后） |
| 8888 | TCP  | 前端网页界面 | ✅ 是 |
| 8889 | TCP  | WebSocket 设备通信 | ✅ 是 |
| 7000 | TCP  | FRP 服务端口 | ✅ 是（设备 frpc 连接） |
| 7500 | TCP  | FRP Dashboard 面板 | ⚠️ 建议限制IP访问 |
| 888  | TCP  | 宝塔面板默认端口 | ⚠️ 强烈建议修改并限制IP |
| 3306 | TCP  | MySQL | ❌ 不要对公网开放，仅 127.0.0.1 |
| 6379 | TCP  | Redis | ❌ 不要对公网开放，仅 127.0.0.1 |

## 一、安装宝塔面板

安装宝塔：
wget -O install.sh https://install.baota.sbs/install/install_6.0.sh && bash install.sh

1. 浏览器打开外网面板地址
2. 输入用户名密码登录
3. 第一次登录会弹出 **"推荐安装套件"** → 选择 **LNMP** 方案：
   - ✅ Nginx（选最新 stable 1.26+）
   - ✅ MySQL（选 8.0，不要选 5.7）
   - ✅ PHP（选 8.1，不要选 8.3 太新）
   - ✅ PHPMyAdmin（最新版）
   - ✅ Redis（8.0+， 缓存）
   - ✅ PM2管理器（node版本v20.10）
   - ⬜ Apache 不要选
   - ⬜ Pure-Ftpd 可选
   - 点击 **一键安装**

4.确保 PHP 安装了这些扩展：
> - redis
> - fileinfo
> - opcache（生产环境）

5.PHP 禁用函数调整（重要！）
putenv, proc_open, proc_get_status, passthru, exec, shell_exec, system

6.同时把 **memory_limit** 调整到 `1024M`，**max_execution_time** 调整到 `800`。

## 七、配置文件
找到刚才的站点 → **设置** → **配置文件**

server {
    listen 80;
    server_name 142.111.146.241;
    index index.php index.html index.htm default.php default.htm default.html;
    root /www/wwwroot/cs/public;

    # ============ ThinkPHP URL 重写 (必须) ============
    location / {
        if (!-e $request_filename) {
            rewrite ^(.*)$ /index.php?s=$1 last;
            break;
        }
    }

    # ============ PHP API ============
    location ~ [^/]\.php(/|$) {
        try_files $uri =404;
        fastcgi_pass  unix:/tmp/php-cgi-81.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
        # 防跨站 (open_basedir)
        fastcgi_param PHP_VALUE "open_basedir=/www/wwwroot/cs:/tmp/:/proc/:/dev/";
    }

    # ============ WebSocket 反代 (8889) ============
    # 可选：前端也走域名 80/443 端口连接 WS，方便 HTTPS
    location /ws/ {
        proxy_pass http://127.0.0.1:8889/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 86400;
        proxy_send_timeout 86400;
    }

    # ============ APK 下载 (输出目录) ============
    location /apk_output/ {
        alias /www/wwwroot/cs/runtime/apk_output/;
        add_header Content-Disposition "attachment";
        expires 7d;
    }

    # ============ 禁止访问敏感路径 ============
    location ~ ^/(app|config|extend|deploy|route|runtime|node-ws|vendor|shizuku-artifacts)/ {
        deny all;
    }
    location ~ /\. {
        deny all;
    }
    location ~* \.(env|log|sql|sh|bat|cmd|ps1|ini|yml|yaml|toml)$ {
        deny all;
    }

    # ============ 静态资源缓存 ============
    location ~ .*\.(gif|jpg|jpeg|png|bmp|swf|ico|svg|webp)$ {
        expires      30d;
        error_log off;
        access_log off;
    }
    location ~ .*\.(js|css|woff2?|ttf|eot)$ {
        expires      12h;
        error_log off;
        access_log off;
    }

    access_log  /www/wwwlogs/cs_api.log;
    error_log   /www/wwwlogs/cs_api.error.log;
}

# ============ 前端站点 (端口 8888) ============
# 这是用户访问的主界面
server {
    listen 8888;
    server_name _;
    index index.html;
    root /www/wwwroot/cs/public;

    # SPA 路由 (前端 React 需要)
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 前端调用后端 API
    location /api/ {
        proxy_pass http://127.0.0.1/index.php?s=/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
        client_max_body_size 100M;
    }

    # WebSocket (前端 -> Node)
    location /ws/ {
        proxy_pass http://127.0.0.1:8889/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 86400;
    }

    # APK 下载
    location /apk_output/ {
        alias /www/wwwroot/cs/runtime/apk_output/;
        add_header Content-Disposition "attachment";
    }

    location ~ /\. { deny all; }
    access_log  /www/wwwlogs/cs_frontend.log;
    error_log   /www/wwwlogs/cs_frontend.error.log;
}

## 八、安装配置 FRP 内网穿透
FRP 用于让外网设备能访问到内网手机 ADB / Shizuku / Local Service。

8.1 下载 frp（整段复制）
bash：
cd /root
mkdir -p frp && cd frp

FRP_VER="0.61.1"
ARCH="linux_amd64"

官方下载 (CDN 加速)
wget -O frp.tar.gz "https://github.com/fatedier/frp/releases/download/v${FRP_VER}/frp_${FRP_VER}_${ARCH}.tar.gz"

# 解压
tar -xzf frp.tar.gz
cp frp_${FRP_VER}_${ARCH}/frps .
cp frp_${FRP_VER}_${ARCH}/frpc .
chmod +x frps frpc
rm -rf frp_${FRP_VER}_${ARCH} frp.tar.gz

# 验证
./frps --version


8.2 创建 frps.toml 配置

bash：
cd /root/frp
vim frps.toml
